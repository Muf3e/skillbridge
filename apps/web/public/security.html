Zero-Trust Threat Model

Adversary Vectors vs. Enclave Mitigations

SkillBridge treats host cloud operators, colocation data center engineers, and neighboring containers as untrusted adversarial actors.

Vector #01 memory

Host Hypervisor Memory Snooping

Malicious or subpoenaed cloud hypervisors directly dumping physical host DRAM pages to extract agent memory, proprietary MCP prompt buffers, or private credentials.

shield SkillBridge Mitigation

Hardware-enforced 512-bit AES-XTS memory encryption. Memory keys are generated by AMD's on-die Secure Processor and never exposed to the host CPU or hypervisor bus.

Vector #02 data_loss_prevention

Prompt Extraction & Weight Scraping

Replay attacks and cold-boot physical bus probes designed to siphon specialized publisher agents, proprietary domain knowledge weights, and context buffers.

shield SkillBridge Mitigation

Stateless in-memory execution. MicroVMs are ephemeral lifecycles strictly limited to 64MB RAM. 100% zero-page scrubbing is executed by the kernel post-call before teardown.

Vector #03 router

Network Man-in-the-Middle Egress

Compromised third-party dependencies within user toolchains attempting unauthorized sideband exfiltration over TCP/UDP external sockets during runtime.

shield SkillBridge Mitigation

Deterministic Airgap nftables enforcement. Physical virtual network adapters are unmapped. Execution occurs over dedicated Unix Domain Sockets mapped strictly to the MCP bridge.

Vector #04 currency_exchange

Escrow & Payment Tampering

Unverified invoice inflation, fabricated invocation claims by rogue nodes, or front-running agent execution fees without proof of actual execution.

shield SkillBridge Mitigation

Cryptographic ZK-Receipt issuance. MicroVM creates an execution digest containing input hash, output state, and hardware attestation signature before escrow unlocks.
